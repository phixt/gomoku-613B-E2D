# Gomoku 613B-E2D

**Discrete 3D Tactical Gomoku**

一款基于离散视角的三维战术五子棋。项目采用双面板架构，将 2D 正交落子界面与 3D 透视战术沙盘完美融合，提供极具深度的空间博弈体验。
> 几乎纯vibe coding。
---

## ️ 重要提示

> **游戏开始后，由于初始 3D 视角设定较远，请先按下 `S` 键将左视图拉远（缩小 FOV），即可看到完整的棋盘图形。**

---

## 🎮 操作指南

### 3D 空间与视角
| 按键 | 功能 |
| :--- | :--- |
| **`Q` / `E`** | 旋转 3D 视角（绕 Y 轴） |
| **`W` / `S`** | 推拉 3D 视角（缩放/聚焦） |
| **`Z` / `C`** | 调整层间距（压缩 / 拉大 3D 空间） |

### 层级与平面
| 按键 | 功能 |
| :--- | :--- |
| **`A` / `D`** | 切换焦点层级（循环 0-5 层） |
| **`F`** | 翻转 2D 主战场（水平镜像） |

### 显示与对弈
| 按键 / 操作 | 功能 |
| :--- | :--- |
| **`T`** | 切换 亮色 / 暗色 主题 |
| **`H`** | 开启 / 关闭 战术辅助线 |
| **鼠标悬停** | 查看 2D/3D 战术辅助线（己方绿，敌方红）及蓝色定位点 |
| **鼠标点击** | 在当前焦点层落子 |

##  核心特性

- **双面板协同架构**：左侧 3D 透视视图提供全局空间感知，右侧 2D 正交视图提供精准落子操作。
- **战术辅助线系统**：支持 2D/3D 联动渲染，采用红绿差分着色（己方绿色，敌方红色），严格限制 4 格检测范围以优化性能。
- **微观空间控制**：支持动态调整层间距（Z/C），赋予玩家对 3D 空间拓扑的绝对掌控力。
- **水绿宣纸视觉**：采用霞鹜文楷字体，搭配水绿渐变与工程图纸风格的开始界面，兼具古典韵味与战术硬核感。
- **桌面端原生支持**：基于 Tauri 构建，可打包为开箱即用的 Windows 安装包，无浏览器滚动条干扰，体验纯粹。

## 🛠️ 技术栈

- **前端核心**：TypeScript, Three.js, Vite
- **桌面端框架**：Tauri (Rust)
- **字体支持**：LXGW WenKai (霞鹜文楷)

## 🚀 构建与运行

### 开发环境
```bash
# 安装依赖
npm install

# 启动 Vite 开发服务器
npm run dev

# 启动 Tauri 桌面端调试
npm run tauri dev
```

### 生产打包 (Windows)
```bash
# 前端构建
npm run build

# 打包为 Windows 安装包 (NSIS)
npm run tauri build
```
*打包产物位于 `src-tauri/target/release/bundle/nsis/` 目录下。*
